# Music Assets for Rockabilly Reels

This folder contains music and sound effects for the game. Generate music using **Suno AI** with the following prompts:

## 1. Background Music (rockabilly-loop.mp3)

**Suno AI Prompt:**
```
Genre: Rockabilly, 1950s rock and roll
BPM: 130
Style: Upbeat, energetic, classic rockabilly with twangy guitar
Instruments: Electric guitar, upright bass, drums, piano
Mood: Fun, nostalgic, retro diner vibes
Length: 2-3 minutes (loopable)
Description: Fast-paced instrumental rockabilly track perfect for a slot machine, 
reminiscent of Eddie Cochran and Carl Perkins. Clean loop with drum fills on the downbeat.
```

**Technical Requirements:**
- Format: MP3, 128-192 kbps
- BPM: Exactly 130 BPM (critical for synchronization)
- Loop: Must loop seamlessly (fade in/out at loop point)
- Length: 2-3 minutes minimum
- No vocals (instrumental only)

## 2. Drum Hit (drum-hit.mp3)

**Suno AI Prompt:**
```
Single rockabilly drum hit sound
Style: 1950s drum kit, snare hit with bass drum
Duration: 0.1-0.2 seconds
Sharp, punchy, clean sound
No reverb, dry recording
```

**Alternative:** Use royalty-free drum samples from:
- Freesound.org
- Pixabay
- BBC Sound Effects Library

**Technical Requirements:**
- Format: MP3, 128 kbps
- Length: 0.1-0.2 seconds
- Volume: Normalized to -6dB
- Clean cut (no fade)

## 3. Win Stinger (win-stinger.mp3)

**Suno AI Prompt:**
```
Rockabilly victory jingle
BPM: 130
Length: 2-3 seconds
Style: Triumphant guitar riff with drum flourish
Mood: Celebration, excitement, big win feeling
Instruments: Electric guitar, drums, bass
Description: Short celebratory rockabilly riff for big wins (10x+ bet)
```

**Technical Requirements:**
- Format: MP3, 128-192 kbps
- Length: 2-3 seconds
- Quick attack, clear ending
- Complements main background music

## How to Generate Music with Suno AI

1. Go to [Suno.ai](https://suno.ai)
2. Create a free account
3. Click "Create" and paste the prompts above
4. Generate multiple versions and pick the best
5. Download as MP3
6. Place files in this folder with exact names:
   - `rockabilly-loop.mp3`
   - `drum-hit.mp3`
   - `win-stinger.mp3`
